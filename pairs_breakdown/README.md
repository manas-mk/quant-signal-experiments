# Quant signal experiments

Small, self-contained experiments that apply statistical signal-processing ideas to financial time series.

| Folder | Question |
|---|---|
| [`pairs_breakdown/`](pairs_breakdown/) | When does a cointegrated stock pair break down, and can an online CUSUM alarm catch it before the losses do? |

Related project: [eeg-correlation-regimes](https://github.com/manas-mk/eeg-correlation-regimes). It uses the same rolling-correlation and change-point tools on EEG data, and shows why random-matrix significance bounds fail on autocorrelated signals.

Author: Manas Manoj Kumar, B.E. Mathematics and Computing, BITS Pilani Dubai Campus
